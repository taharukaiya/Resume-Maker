# Portfolio typefaces

These are the normal, Latin-subset variable WOFF2 files from the pinned
`@fontsource-variable` packages in package-lock.json. Each accompanying SIL Open
Font License is in `licenses/`. Font names and authors are documented there.

Source: https://fontsource.org/docs/getting-started/variable

Only a portfolio's selected heading/body fonts are copied into its published
release. Font display uses `swap`. Other scripts fall back to installed fonts.
No third-party font request is required. When updating a font package, replace
its WOFF2 and license here, rebuild, and republish affected portfolios.
